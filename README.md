# HKSS Decrypted

An unofficial combo randomizer and [Archipelago](https://archipelago.gg) world for *Hollow Knight* and *Hollow Knight: Silksong*. One seed spans Hallownest and Pharloom: abilities and items from either game can turn up in the other, and you travel between the two games during the run.

- [Website](https://decryptu.github.io/hkss-decrypted/)
- [Architecture](docs/ARCHITECTURE.md)
- [Development setup](DEVELOPMENT.md)
- [Roadmap](ROADMAP.md)

## Play

First playtest release: download the installer and `hkss.apworld` from the [latest release](https://github.com/Decryptu/hkss-decrypted/releases/latest), then follow [How to Play](https://decryptu.github.io/hkss-decrypted/#journey). Requires Windows, Hollow Knight 1.5.12620 and Silksong 1.0.30000 on Steam, and Archipelago 0.6.8 or newer.

- **One mod for both games** on BepInEx 5: Hollow Knight's randomizer and [Silksong Decrypted](https://github.com/Decryptu/silksong-decrypted) ported to the current Steam builds.
- **One Archipelago game**, `Hollow Knight x Silksong`: one YAML and one slot covering both games, with single-game modes.
- **HKSS Launcher**: runs modded copies of both games (your Steam installs stay vanilla), keeps each run's saves apart, travels between games behind a loading screen, and exports bug reports.
